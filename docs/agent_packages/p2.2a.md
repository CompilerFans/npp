## 1. 范围

模块 `nppi_data_exchange_and_initialization.h`：
- `nppiSwapChannels`（70 待实现）：C3/C4 通道重排；`aDstOrder[3/4]` 排列；含原地 `_I` 变体；Ctx/非 Ctx。
- `nppiCopySubpix`（40 待实现）：带亚像素偏移 `nDx/nDy` 的复制（NPP 语义以 5090 record 为准）。

## 2. 语义要点

- 2D ROI + step；只写 ROI，padding 不变；空 ROI `NPP_NO_ERROR`；负 ROI 以 5090 为准（P2.1c 实测为 no-op）。
- SwapChannels：`aDstOrder` 的越界/重复校验/状态码以 5090 为准；原地版本读写同一缓冲区。
- CopySubpix：分数偏移的插值/边界行为必须逐点对比 5090；测试覆盖 0、±0.25、±0.5、接近 1 的偏移。
- 使用 `nppStreamCtx.hStream`；launch 前清空陈旧 CUDA error。

## 3. 交付物

- `nppi_swapchannels`/`nppi_copy_subpix` executor（2D kernel + 校验），复用现有 swapChannels 实现模式。
- 生成器生成 wrapper（排列/in-place/亚像素参数不规则时可写专用生成器）；生成文件入库。
- `test/unit/diff/test_nppi_swap_subpix_generated.cpp`（suite `NppiSwapSubpixDiff`）：
  - SwapChannels：C3/C4 全部排列（3! / 4! 代表子集）× 代表 dtype；原地与非原地；step padding 不变；
  - CopySubpix：多个分数 dx/dy、边界 ROI、C1/C3/C4；
  - contract：空指针、空 ROI、非法 order、step 不足。
- 覆盖率刷新。
