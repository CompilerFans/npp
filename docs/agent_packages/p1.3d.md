## 1. 范围

| 项 | 值 |
|---|---|
| 模块 | `nppi_statistics_functions.h` |
| 家族 | `nppiMaximumError`、`nppiMaximumErrorGetBufferHostSize`、`nppiMaximumRelativeError`、`nppiMaximumRelativeErrorGetBufferHostSize` |
| 函数 | 352（全部待实现） |
| 变体 | 11 种 dtype × C1/C2/C3/C4/AC4 × Ctx/非 Ctx；无 masked/COI |

语义（以 NPP 头文件 max 组文档为准）：
- `MaximumError = max |pSrc1 - pSrc2|`（按通道；复数按 `|z|`）；
- `MaximumRelativeError = max |pSrc1 - pSrc2| / max(|pSrc1|, |pSrc2|)`；
- 输出 device `Npp64f`（C3/C4 为每通道数组），scratch 用 `pDeviceBuffer`。

## 2. 语义要点（必须以 5090 实测为准）

- **零分母**：`max(|a|,|b|)==0` 的像素在 MaximumRelativeError 中如何处理，必须用探针钉死（与 P1.3c 的 Average 相对误差保持同一约定，但不要假设相同）。
- **初始值**：空 ROI / 单像素 / 全零输入的返回值（0？类型最大值？）以 golden 为准。
- **通道数**：AC4 是否包含 alpha、C3 是否为每通道数组，以 5090 为准。
- **Buffer host size**：全部 176 个 helper 的参数是 `int * hpBufferSize`；只承诺 status 与“按返回值分配后调用成功”，精确字节数不作契约。
- 非 Ctx 入口由生成器统一转发；NPP 13 只验证 Ctx；launch 前清空陈旧 CUDA error。
