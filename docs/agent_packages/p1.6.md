## 1. 范围

| 项 | 值 |
|---|---|
| 模块 | `nppi_morphological_operations.h` |
| 家族 | Dilate/Erode（普通、3x3）、Dilate/ErodeBorder、3x3Border、MorphGradient/Open/Close/TopHat/BlackHat（含 Border）、MorphGetBufferSize、GrayDilate/GrayErodeBorder |
| 函数 | 268（见 package CSV） |

语义要点（以 5090 实测为准）：
- 普通版：任意 `oMaskSize`/`oAnchor` + `pMask`；3x3 版固定 3×3。
- Border 版：`eBorderType`（REPLICATE / CONSTANT / WRAP 等）、`nSrcBorder`/常量值；边界像素的语义必须差分验证。
- Gray 形态学：结构元素为灰度模板（min/max 加性），不是二值 mask。
- `nppiMorphGetBufferSize`：只承诺 status 与“按返回值分配后调用成功”，精确字节数不作契约。
- step/ROI/空 ROI/负 ROI 的状态码与校验顺序以 golden 为准；launch 前清空陈旧 CUDA error。
