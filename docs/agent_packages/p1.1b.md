## 2. 语义要点

- 常量运算：`pDst = pSrc op c`；原地：`pSrcDst op= c`。
- `_Sfs` / `_ISfs` 变体带 `nScaleFactor`，整数缩放/饱和/舍入语义必须与 NPP 13.4 差分结果一致。
- `nppsSubCRev`：`pDst = c - pSrc`（注意操作数顺序）；`nppsDivCRev`：`pDst = c / pSrc`。
- `nppsAddProductC_32f`：累加语义 `pDst += pSrc * c`，`pDst` 是输入输出；不要覆盖。
- `nppsMulC_Low_32f16s`：NPP 的 "Low" 语义（乘法结果取低位写入 16s 输出），以 5090 差分结果为准。
- `nppsNormalize_16s_Sfs` / `16sc_Sfs`：`vSub`、`vDiv`、`nScaleFactor` 的组合语义；先读 NPP 头文件注释再实现。
- 位运算常量变体（AndC/OrC/XorC）只对有符号/无符号整数类型存在。
