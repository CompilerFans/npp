待实现 160 个，覆盖：

- `_Ctx` 与非 `_Ctx` 入口。

## 2. 语义要点

- 纯拷贝，不做类型转换；2D ROI + 行 step。step 不足返回 `NPP_STEP_ERROR`（以 5090 record 为准）。
- 空 ROI → `NPP_NO_ERROR`；负尺寸 → `NPP_SIZE_ERROR`；空指针（含 planar 的任一平面指针）→ `NPP_NULL_POINTER_ERROR`。
- 只在 ROI 内写；行尾 padding 保持原值。
- packed 同类型可直接 `cudaMemcpy2DAsync`；planar/互转用 2D kernel。
- 使用 `nppStreamCtx.hStream`；launch 前清空陈旧 CUDA error。
