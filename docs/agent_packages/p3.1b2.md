## 2. 语义要点

- NormRel = norm(pSrc1-pSrc2) / norm(pSrc2)（以 5090 为准，注意分母/零除）。
- DotProd：逐像素/逐通道乘积和，输出 device 标量/数组；masked/COI 以 5090 为准。
- NormLevel buffer helpers：为 CrossCorr NormLevel 预留 scratch 大小；只校验 status 与“用返回值分配后调用成功”，精确大小不作契约。
- 复用 P3.1a/b 的 reduction executor；double 累加。
- 非法输入探针避开已知 5090 设备 fault 的场景；状态以 record 为准。
