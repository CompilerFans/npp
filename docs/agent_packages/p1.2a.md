## 2. 语义要点

- `nppsSet_*`：把标量值写入 `nLength` 个元素；支持整数/浮点/复数/`Npp16f`/64 位类型。
- `nppsCopy_*`：同类型逐元素复制；注意 64sc 等大类型。
- `nppsZero_*`：等价于 Set 0；可用 `cudaMemsetAsync`（字节 0）优化。
- `nLength` 使用 `NppSignalLength`（MPP 为 int，NPP 13 为 size_t）。
- 空指针、`nLength == 0`、负长度的状态必须与 NPP 13.4 差分一致。
- 使用 `nppStreamCtx.hStream`；非 Ctx 由生成器转发。
