## 2. 要求

1. 先读模块现有实现与最近邻家族，复用 P0.1 公共工具与既有 executor 模式。
2. 每家族：executor/kernel → `mpp_scripts/families/*.json` + `gen_family.py` 生成 wrapper（生成文件入库）→ 差分测试。
3. **45 分钟内必须产生第一个 commit**；每完成一个家族（实现 + 5090 record 通过）立即提交。
4. 测试目录：`test/unit/diff/`，suite 命名按家族；覆盖 dtype × channels × 边界/错误路径。
5. 语义以 5090 实测为准（状态码、ROI/step 校验顺序、空/负 ROI、alpha 约定）。

## 3. 环境

- **worktree 内不做本地 MPP build**（cu-bridge/CMake 限制）。
- 使用 **mcpp-5090 MCP**：`sync`（repo_path=当前 worktree，remote_dir=`/home/metax/mcMPP-s1`）、`build`（远端 NVIDIA NPP）、`record`（`NPP_RECORD_DIR`，target=`diff_tests`）、`pull`。
- golden 与测试由 Lead 在 C500 做 MPP 侧验证；你只需保证 5090 record 全绿。
- 测试代码需同时适配本地与 NVIDIA 头文件（`SIZE_TYPE` 约定）。
