## 1. 范围

模块 `nppi_data_exchange_and_initialization.h`：
- `nppiSet`（168 total，24 real，144 待实现）：ROI 填常量；C1 单标量、C3/C4 三/四元素数组、AC4 三元素数组（alpha 保持）；Ctx/非 Ctx。
- `nppiDup`（30 待实现）：单通道复制到 C3/C4/AC4 等目标（`C1C3R/C1C4R/C1AC4R/...`，以头文件/CSV 为准）。

## 2. 语义要点

- 2D ROI + step；只在 ROI 内写，padding 不变。
- 空 ROI → `NPP_NO_ERROR`；负尺寸 → `NPP_SIZE_ERROR`；空指针 → `NPP_NULL_POINTER_ERROR`；step 不足 → `NPP_STEP_ERROR`（以 5090 record 为准）。
- AC4 Set 不修改 alpha；Dup 的 alpha 行为按目标布局（AC4 保持/复制，以 5090 为准）。
- 使用 `nppStreamCtx.hStream`；launch 前清空陈旧 CUDA error。

## 3. 交付物

- 扩展 `nppi_set`/新增 `nppi_dup` executor：2D 模板 kernel + 校验。
