## 2. 语义要点（以 5090 差分为准）

- 2D ROI：`oSizeROI` 为像素尺寸；`nSrcStep/nDstStep` 为行字节跨度。
- 最小 step = `width * channels * sizeof(dtype)`；step 不足返回 NPP_STRIDE_ERROR（或 NPP_STEP_ERROR，必须用 5090 record 确认）；空 ROI（宽或高为 0）→ `NPP_NO_ERROR`；负尺寸 → `NPP_SIZE_ERROR`；空指针 → `NPP_NULL_POINTER_ERROR`。
- ROI 只在 `oSizeROI` 内写；行尾 padding 必须保持原值。
- 转换规则：
  - 整数→整数：饱和（8u/8s/16u/16s/32u/32s/64u/64s），不 wrap。
  - 浮点→整数：按 `NppRoundMode`（`NPP_RND_NEAR` 等）舍入后再饱和；`NaN/±Inf` 行为以 5090 为准。
  - 整数/浮点→浮点：直接转换；16f/32f/64f 精度按签名。
  - 复数/多通道：按分量转换，通道数/布局由签名决定。
- 所有 kernel 使用 `nppStreamCtx.hStream`；launch 前清空陈旧 CUDA error（`(void)cudaGetLastError()`）。
