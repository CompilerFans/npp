## 2. 语义要点

- `nppsConvert_<src><dst>`：逐元素类型转换；整数饱和/舍入、浮点→整数截断、16f/64sc 的行为以 NPP 13.4 差分为准。
- `nppsThreshold_*`：
  - `nppsThreshold_8u(const Npp8u *pSrc, Npp8u *pDst, int nLength, Npp8u nLevel, NppCmpOp nRelOp)`：比较后把不满足条件的元素置 0（按 NPP 文档确认保留/清零方向）；
  - `_GTVal` / `_LTVal` / `_LTValGTVal`：带替换值的变体；
  - 支持原地版本（若签名存在）。
- 阈值比较使用 `NppCmpOp`（NPP_CMP_LESS / LESS_EQ / EQUAL / GREATER_EQ / GREATER / NOT_EQUAL）。
- `NppSignalLength` 类型兼容；`nppStreamCtx.hStream`。
- 状态码/边界以 5090 record 为准。

## 3. 交付物
