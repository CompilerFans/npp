## 1. 范围

## 2. 语义要点

- 2D ROI 范数：L1=Σ|a|、L2=√Σa²、Inf=max|a|；NormDiff 对 `pSrc1-pSrc2` 求范数。
- 输出 device 标量（C1）或每通道数组（C3/C4）；masked/COI 语义以 5090 为准。
- Buffer-size helper 只校验 status 与“用返回值分配后调用成功”，精确大小不作契约。
- 空 ROI/负尺寸/空指针/step 的 status 以 5090 record 为准；避开已知会触发 NVIDIA 设备 fault 的非法探针（P3.1a2/a3 已遇到）。
- 复用 P3.1a1 的 reduction executor，扩展 L1/L2/Inf 策略（double 累加，Inf 需处理 NaN）。
- 使用 `nppStreamCtx.hStream`，launch 前清空陈旧 error。
