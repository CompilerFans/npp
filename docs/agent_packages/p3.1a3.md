## 1. 范围

模块 `nppi_statistics_functions.h`：
- `nppiMinIndx` / `nppiMaxIndx` / `nppiMinMaxIndx` + 对应 `GetBufferHostSize`；
- `nppiMinEvery` / `nppiMaxEvery`（逐元素 min/max 合并）。

## 2. 语义要点

- 索引归约输出：最小值/最大值（device）+ 索引（通常 `Npp32s x,y` 或每通道数组）；索引基准、masked/COI、平局规则以 5090 为准。
- MinEvery/MaxEvery：`pSrcDst[i] = min/max(pSrcDst[i], pSrc[i])`，原地；通道/step 语义。
- Buffer-size helper 只校验 status 与“用返回值分配后调用成功”，精确大小不作契约。
- 空 ROI/负尺寸/空指针/step 的 status 以 5090 record 为准；对会触发 NVIDIA 设备 fault 的非法探针要避开（P3.1a2 已遇到：Min/Max 非法输入会在 5090 上延迟 fault）。
- 复用 P3.1a1/P3.1a2 的 reduction executor；索引输出用 `device_output(..., I32/F32/F64)`。
