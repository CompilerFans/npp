## 2. 语义要点

- Threshold：按 `NppCmpOp`/家族把 `pSrc` 与 level 比较后置 0/`nValue`/level；原地变体；AC4 保留 alpha。
- Compare：输出 `Npp8u`（真 255 / 假 0）；`CompareC` 与标量比较；`EqualEps` 用 `nEpsilon`；Ctx/非 Ctx。
- 2D ROI + step；空 ROI/负尺寸/非法 level 的状态以 5090 record 为准；step 不足 → `NPP_STEP_ERROR`（或实测值）。
- 使用 `nppStreamCtx.hStream`；launch 前清空陈旧 CUDA error。

## 3. 交付物

- threshold/compare executor（2D 模板 kernel + 校验/策略），复用现有实现的 wrapper 风格。
- 生成器生成 wrapper；生成文件入库，不手改。
- `test/unit/diff/test_nppi_threshold_compare_generated.cpp`（suite `NppiThresholdCompareDiff`）：
  - 每个家族 × 代表 dtype × {C1,C3,C4,AC4}；
  - 比较操作全集（LESS/LESS_EQ/EQUAL/GREATER_EQ/GREATER/NOT_EQUAL）、边界 level（0/1/mid/max）、`nValue` 变体；
  - Compare 的 255/0 输出、EqualEps 的 epsilon 边界；
  - 尺寸 {1x1,17x13,64x32}、padding step；AC4 alpha 不变；
  - contract：空指针、空 ROI、负尺寸、step 不足、非法 level。
- 覆盖率刷新。
