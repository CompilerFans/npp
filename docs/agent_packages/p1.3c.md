## 1. 范围

| 项 | 值 |
|---|---|
| 模块 | `nppi_statistics_functions.h` |

| 函数 | 352（348 待实现，4 已 real） |
| 变体 | 11 种 dtype × C1/C2/C3/C4/AC4 × Ctx/非 Ctx；无 masked/COI |

语义（NPP 头文件）：设 N 为通道数，
- `AverageError = 1/(W·H·N) · Σ |pSrc1 - pSrc2|`
- `AverageRelativeError = 1/(W·H·N) · Σ |pSrc1 - pSrc2| / max(|pSrc1|, |pSrc2|)`
- 复数类型按 `|z|` 计算；输出为 device `Npp64f` 标量，scratch 用 `pDeviceBuffer`。

## 2. 语义要点（必须以 5090 实测为准）

- **零分母**：`AverageRelativeError` 中 `max(|a|,|b|)==0` 的像素如何处理（跳过？计 0？计源类型最大值？）必须用 5090 探针钉死——沿用 P3.1b2 的方法：用相同 RNG 复现输入、从 golden 解码精确的分子/分母，不要猜。
- **累加精度**：double 累加；大图/大值下的舍入以 golden 为准。
- **通道数 N**：AC4 是否按 4 通道归一化、是否包含 alpha 通道，以 5090 为准。
- **Buffer host size**：`GetBufferHostSize` 只承诺 status 与“按返回值分配后调用成功”；精确字节数不作为契约。注意全部 176 个 helper 的参数是 `int * hpBufferSize`。
- 非 Ctx 入口由生成器统一 `nppGetStreamContext` 转发；NPP 13 只验证 Ctx。
- launch 前清空陈旧 CUDA error；使用 `nppStreamCtx.hStream`。
