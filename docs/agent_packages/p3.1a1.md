## 2. 语义要点

- 2D ROI 归约；输出为 device 标量（C1）或每通道数组（C3/C4）；`pDeviceBuffer` 为 scratch。
- Sum/Mean 的累加精度、饱和/溢出、masked 语义以 5090 为准；Mean_StdDev 同时输出均值/标准差（两个 device 指针）。
- Buffer-size helper 返回 host 大小；**精确字节数不是契约**（我们返回自己实现所需的大小即可），测试只校验 status 与“用返回值分配后调用成功”。
- 空 ROI/负尺寸/空指针/step 的 status 以 5090 record 为准；使用 `nppStreamCtx.hStream`，launch 前清空陈旧 error。
- 归约 kernel 的线程块/共享内存方案可复用 `npps_sum` 的两段式归约。

## 3. 交付物
