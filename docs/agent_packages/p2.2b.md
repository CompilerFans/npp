## 1. 范围

模块 `nppi_data_exchange_and_initialization.h`：
- `nppiScale`（64 待实现）：把图像值域映射到 `[nMin,nMax]`（签名 `(pSrc,nSrcStep,pDst,nDstStep,oSizeROI,nMin,nMax)`，dtype 对/通道以 CSV 为准）。
- 边界复制（118 待实现）：
  - `nppiCopyConstBorder`（38）：源 ROI 放到目标 `(left,top)`，其余边界填常量；
  - `nppiCopyReplicateBorder`（40）：边界复制最近像素；
  - `nppiCopyWrapBorder`（40）：环绕边界。

## 2. 语义要点

- 2D ROI + step；只在 `oDstSizeROI` 内写，padding 不变。
- 空 ROI/非法 border（负值、超过目标尺寸）以 5090 record 为准；空指针 → `NPP_NULL_POINTER_ERROR`。
- Scale 的映射公式、取整/饱和（整数目标）以 5090 为准。
- ConstBorder 的 `nValue` 按 dtype/通道；Replicate/Wrap 的索引规则以 NPP 为准。
- 使用 `nppStreamCtx.hStream`；launch 前清空陈旧 CUDA error。

## 3. 交付物

- `nppi_scale`/`nppi_border_copy` executor（2D kernel + 校验）。
- 生成器生成 wrapper；生成文件入库，不手改。
- `test/unit/diff/test_nppi_scale_border_generated.cpp`（suite `NppiScaleBorderDiff`）：
  - Scale：每 dtype 对 × 代表通道，nMin/nMax 多组（含 0/最大值/负范围），尺寸 {1x1,17x13,64x32}；
  - Border：top/left/right/bottom 组合（0/1/3），padding 不变，三种 border 模式；
  - contract：空指针、空 ROI、负 border、step 不足。
- 覆盖率刷新。
