## 2. 语义要点

- 2D ROI 归约；输出 device 标量（C1）或每通道数组（C3/C4）；`pDeviceBuffer` 为 scratch。
- 比较/NaN/Inf/masked 语义以 5090 为准；MinMax 的两个输出指针。
- Buffer-size helper 只校验 status 与“用返回值分配后调用成功”，精确大小不作契约。
- 空 ROI/负尺寸/空指针/step 的 status 以 5090 record 为准；使用 `nppStreamCtx.hStream`，launch 前清空陈旧 error。
- 复用 P3.1a1 的 reduction executor（扩展 Min/Max/MinMax 策略）。
