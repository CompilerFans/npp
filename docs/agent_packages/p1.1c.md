## 2. 语义要点

- 一元 Sfs 变体的缩放/饱和/舍入必须与 NPP 13.4 差分一致；`nppsSqrt_64s16s_Sfs` 等混合输出类型要按签名处理。
- `nppsSumLn`：对输入逐元素取自然对数后求和（标量输出），需要 device buffer；`GetBufferSize` 返回的 scratch 大小只需保证本地实现可用（不要求与 NPP 数值相同）。
- 位运算只对整数类型；移位常量范围/越界行为以差分结果为准。
- `nppsMul_Low_32s_Sfs` 取 64 位乘积的低 32 位再缩放；确认符号扩展行为。
- `nppsCauchy*` 是原地分布函数；先读 `API/npps_arithmetic_and_logical_operations.h` 的公式说明。
- 所有 kernel launch 前清空陈旧 CUDA error。

## 3. 交付物

- 扩展现有 1D 执行器：一元、位运算、移位、标量归约（SumLn）。
- 每个 family 一个 spec，生成 wrapper 到 `src/npps/npps_arithmetic_operations/`。
- `test/unit/diff/test_npps_unary_generated.cpp`：每种 dtype × {普通, Sfs, 原地} × {Ctx, 非 Ctx} 代表形状；SumLn 单独 reduction case；Cauchy/Mul_Low 单独 case。
- contract case：空指针、`nLength == 0`、负长度、移位越界。
- 覆盖率刷新。
