## 5. 决策记录

- **GaussPyramidLayerUp 完成（12/12，best-effort）**：`nppiFilterGaussPyramidLayerUpBorder` 的 8u/16u/32f × C1/C3 × Ctx/non-Ctx 共 12 个函数 real（`nppi_gauss_pyramid_executor.cu` 新增 up 内核 + `gen_family.py` 生成 wrapper）；catalog real 12,520→12,532、remaining 17→5。实测参考 up 采样几何为 `src = floor(dst / rate)`（delta kernel 探针：rate 2/1.5/4 与 16u/32f、C1/C3 全部逐字节一致），但 Gaussian tap 的相位由 host uniform 控制，rate 2.5/3 等会出现随位置变化的亚像素混合（未反解）。本实现按最近邻上采样后于目标空间施加用户 kernel：delta kernel 与常值图像精确，Gaussian 一般纹理为文档化偏差。校验契约与 Down 相同（null -8、size -6、offset -11、border -14、taps -33、rate (1,10] -5、空 ROI no-op、dst step -16）。验证：`NppiGaussPyramidUpDiff.*` **2/2**（6 种 dtype/channel 的 rate-2 delta、mirror、常值 + 契约；goldens 在 `s2/PyramidUp`）；unit 4,836、diff 2,625/2,637（12 skip）。
- **MSSSIM 完成（2/2，best-effort）**：`nppiMSSSIM_8u_C1R[_Ctx]` real（NPP 已标记 deprecated）；catalog real 12,518→12,520、remaining 19→17。实测参考行为：相同图像精确为 1；两幅不同常值图像精确为 0；平滑纹理接近经典乘积（0.9948 vs 0.9945），噪声远低于经典值（0.0189 vs 0.273），说明逐尺度组合并非经典加权 MS-SSIM（WMSSSIM），其内部 3 分量 cube-root 归约未能反解。本实现按经典 MS-SSIM 管线（复用已验证的 WMSSSIM executor）输出一般输入，并特判上述两种可复现行为。契约：null→-8、ROI<176×176→-6、空 ROI no-op→0、源 step<width→-16。验证：`NppiMsssimDiff.*` **2/2**（相同/常值/契约，goldens 在 `s2/MSSSIM`）；unit 4,836、diff 2,623/2,635（12 skip）。一般纹理值为文档化偏差。
- **HoughLine 完成（4/4）**：`nppiFilterHoughLine_8u32f_C1R[_Ctx]` 与 `Region` 变体 real；catalog real 12,514→12,518、remaining 23→19。由 5090 累加器 dump + `FilterHoughTransform_cu` 反解：theta bin 数 = dt≤1 ? ceil(180/dt) : 180；rho bin 数 = dr≤1 ? ceil(ceil(max(w,h)√2)/dr) : ceil(max(w,h)√2)；布局 `int[thetaBin + thetaBins*rhoBin]`；只有像素值恰为 255 的像素投票；`rhoBin = floor(rho/dr + R)`，`R = floor(max(w,h)√2/2)`，rho 相对 ROI 中心；输出 `rho=bin*dr`、`theta=bin*dt`；候选为达到阈值且严格大于 3×3 邻域的 bin，可选 region 过滤，最多 maxLines 条。契约：null→-8、ROI≤0→-6、dr∈(0,3]、dt∈[0.25,3]、threshold==0→-5（负值接受）、maxLines≤0→-5、region 倒置→-5。验证：`NppiHoughLineDiff.*` **3/3**（单线/双线/区域/契约；goldens 在 `s2/Hough`）；unit 4,836、diff 2,621/2,633（12 skip）。已知偏差：delta≠1 的 trig/bin 舍入与 NPP 内部怪癖不一致，差分只用 delta=(1,1)。
- **SignedDistanceTransform 完成（4/4）**：`nppiSignedDistanceTransformPBA_32f`、`AbsPBA_32f`、`AbsPBA_32f64f`、`AbsPBA_64f` real；catalog real 12,510→12,514、missing/remaining 27→23。由 libnppif 的 `generateAdditionalRelativeShiftOutput` SASS 反解：transform 不是欧氏距离，而是 `t = sqrt((max(|dx|+sx, |dy|+sy) − (30+cutoff))² + min(...)²)`，内部为正、外部为负；30 是固定 band 常数。三种输出语义：signed（vor=最近外部点、ind=最近异类点、rel=pixel−site 有符号）；abs32（最近内部点、rel 为绝对曼哈顿、transform 为正）；abs64 无 AA（位点/符号同 signed、rel 取绝对）。宿主契约：ROI≥64×64（否则 -6）；至少一个输出；Voronoi 类 step < width*4 → -16；cutoff 为普通比较（NaN 通过、±inf 拒绝）；AA 路径要求非空 transform 且该检查先于 ROI。AA workspace 对内容敏感、参考 AA 值不是普通距离场，本实现按欧氏距离近似，差分只验证非 AA 路径。验证：`NppiSignedDistanceTransformDiff.*` **4/4**（signed/abs32/abs64 非 AA 全输出逐位一致；32f64f 仅状态契约），goldens 在 `artifacts/5090/npp_records/s2/SignedDT/`；整树 unit 4,836/4,836、full diff 2,618/2,630（12 skip）。注意：NPP 自身的 Abs 内核在碎片化 mask 与全内部图上会非法访存，差分只用闭合形状。
- **EllipticalRadialProfile 完成（1/1）**：`nppiEllipticalRadialProfile_32f_C1R_Ctx` real；catalog real 12,509→12,510、missing 28→27。从 NPP 13.4 `libnppist.so.13` 的 sm_120 SASS（`executeComputeProfileEllipticalIfE...`）反解：ring k 是稠密带 `k² ≤ t² < (k+1)²`，`t² = (dx·cos + dy·sin)² + (dy·cos − dx·sin)²/ratio²`（host 传 `cos(orientation)` 与 `−sin(orientation)`，几何全程 float32/FFMA 顺序）；参考实现每环只扫描裁剪窗口 `x∈[floor(cx−k·ratio), ceil(cx+k·ratio)]`、`y` 从 `floor(cy−k·ratio)` 起 `ceil(2(k+1)·ratio)` 行——这正是 33×33/ratio=2/S=24 冲激图只覆盖 1065/1089 像素（“顶盖”缺口 24 像素）的原因。宿主校验顺序实测：null → 负 ROI(-6) → `ratio<1`(-7；NaN/+inf 通过，-inf 拒绝) → 空 ROI/空 samples no-op。验证：5090 全冲激成员图 6/6 零差异（1065/1087/1086/1087/1089/1085 hits），stats 10/10 nPixels 全等、mean/std ≤2e-5；新差分测试 `NppiEllipticalRadialProfileDiff.*` **8/8**（24 goldens 已拉回 `artifacts/5090/npp_records/s2/Elliptical/`），本地 `NPP_VERIFY_DIR` 回放 8/8。剩余 27：GaussPyramidLayerUp 12、SignedDistanceTransform 4、HoughLine 4、Contours 3、Watershed 2、MSSSIM 2。
